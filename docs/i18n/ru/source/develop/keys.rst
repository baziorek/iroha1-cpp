===============
Формат пары ключей
===============

Iroha использует пары ключей (.pub и .priv) для подписи
транзакций – у каждого `аккаунта
<../concepts_architecture/glossary.html#account>`_ есть хотя бы
1 пара. Некоторые аккаунты (если `quorum
<../concepts_architecture/glossary.html#quorum>`_ больше 1) могут
иметь больше `подписантов
<../concepts_architecture/glossary.html#signatory>`_,
подписывающих транзакции – и у каждого подписанта есть пара
ключей. Криптографические алгоритмы используют эти ключи – а в
Iroha мы предоставляем вам выбор – какие алгоритмы
использовать.

.. note:: Посмотрите, как создавать пары ключей с помощью
библиотеки Python `здесь
<../getting_started/python-guide.html#creating-your-own-key-pairs-with-python-library>`__.

Поддерживаемые криптографические алгоритмы
=========================================

Нативно HL Iroha использует пользовательский алгоритм – Ed25519 с
SHA-3. Эти ключи поддерживаются всеми версиями Iroha, включая
старые. Но, как мы все знаем, нам также нужны более универсальные
варианты – поэтому у Iroha есть `интеграция HL Ursa
<../integrations/index.html#hyperledger-ursa>`_ – это библиотека
с различными криптографическими алгоритмами, которая позволяет
работать с Irohой, используя более распространённые ключи. Ursa
обеспечивает Irohе поддержку стандартного Ed25519 с алгоритмом
SHA-2.

Публичные ключи
----------------

Чтобы предоставить простое решение, позволяющее использовать
различные алгоритмы без "нарушения" обратной совместимости, мы
ввели формат **multihash** для публичных ключей в Iroha. Вы
можете узнать больше о multihash `здесь
<https://github.com/multiformats/multihash>`__.

Обычно, чтобы использовать ключи, отличные от нативных ключей
ed25519 SHA-3, вам нужно будет привести их к этому формату:

.. code-block:: shell

	<varint key type code><varint key size in bytes><actual key bytes>


.. note:: В multihash varint'ы — это беззнаковые varint'ы
самого значащего бита (также называемые base-128 varint'ами).


Если Iroha получит стандартный 32-байтовый публичный ключ, она
будет считать его нативным ключом Iroha.
Если она получит публичный ключ multihash, она обработает его в
соответствии с таблицей ниже.


Сейчас Iroha "понимает" только один формат ключа multihash:

+------------+-----------+----------+------------------+
|Имя         |Тег        |Код       |Описание          |
+============+===========+==========+==================+
|ed25519-pub |key        |0xed	    |Публичный ключ Ed25519|
+------------+-----------+----------+------------------+

Примеры публичных ключей в Iroha:

+----------------+--------+----------+-------------------------+----------------------+
| тип            | код    | длина    | данные                  | что распознаёт Iroha |
+================+========+==========+=========================+======================+
| ключ multihash | ED01   | 20       | 62646464c35383430b...   | ed25519/sha2         |
+----------------+--------+----------+-------------------------+----------------------+
| сырой 32-байт. | --     | --       | 716fe505f69f18511a...   | ed25519/sha3         |
| ключ           |        |          |                         |                      |
+----------------+--------+----------+-------------------------+----------------------+

Обратите внимание, что код `0xED` кодируется как `ED01` по
правилам формата multihash.

Приватные ключи
----------------

**Приватные ключи** в Ursa представлены конкатенацией приватного
ключа и публичного ключа – без префиксов multihash.
