Библиотека iOS Swift (не поддерживается)
----------------------------------------

.. note::
   Эта страница описывает upstream-библиотеку ``iroha-ios``,
   которая **не поддерживается с 2020 года** (последний релиз
   v4.0.1) — она по-прежнему работает с узлами Iroha 1, но не
   получает обновлений. Для новых проектов предпочитайте
   активно поддерживаемые библиотеки :doc:`cpp` или
   :doc:`python` этого форка.

Библиотека была создана для удобного интерфейса iOS-приложений
для связи с блокчейном Iroha, включая отправку
транзакций/запросов, потоковую передачу статусов транзакций и
коммитов блоков.

Где получить
^^^^^^^^^^^^

Библиотека Iroha iOS доступна через CocoaPods. Для установки
просто добавьте следующую строку в ваш Podfile:

.. code-block:: swift

    pod 'IrohaCommunication'

Вы также можете скачать исходный код библиотеки из `её
репозитория
<https://github.com/hyperledger/iroha-ios>`__


Как использовать
^^^^^^^^^^^^^^^^

Для новых пользователей Iroha рекомендуем ознакомиться с
`примером проекта iOS
<https://github.com/hyperledger/iroha-ios/tree/master/Example>`__.
Он пытается установить соединение с пиром Iroha, который также
должен быть запущен локально на вашем компьютере, чтобы создать
новый аккаунт и отправить на него некоторое количество актива.
Для запуска проекта выполните следующие шаги:

- Следуйте инструкциям из документации Iroha для настройки и
  запуска пира Iroha в docker-контейнере.

- Склонируйте `репозиторий iroha-ios
  <https://github.com/hyperledger/iroha-ios>`__.

- Перейдите в каталог Example и выполните pod install.

- Откройте IrohaCommunication.xcworkspace в XCode

- Соберите и запустите target IrohaExample.

- Проверьте логи, чтобы увидеть, успешно ли завершился сценарий.

Не стесняйтесь экспериментировать с примером проекта и задавать
любые вопросы на `Discord
<https://discord.com/channels/905194001349627914/905205848547155968>`_.
