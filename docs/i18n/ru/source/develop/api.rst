Iroha API reference
===================

В разделе API мы рассмотрим строительные блоки приложения,
взаимодействующего с Irohой. Мы обзорим команды и запросы,
которые есть в системе, и набор клиентских библиотек,
охватывающих транспорт и логику слоя приложения.

API Iroha следует принципу `разделения команд и запросов
<https://en.wikipedia.org/wiki/Command%E2%80%93query_separation>`_.

Коммуникация между пиром Iroha и клиентским приложением
поддерживается через фреймворк `gRPC <https://grpc.io/about/>`_.
Клиентские приложения должны следовать описанному протоколу и
формировать транзакции в соответствии с их
`описанием <../concepts_architecture/glossary.html#transaction>`_.

Команды здесь являются частями `транзакции
<../concepts_architecture/glossary.html#transaction>`_ —
меняющего состояние набора действий в системе. Когда транзакция
проходит этапы валидации и консенсуса, она записывается в `блок
<../concepts_architecture/glossary.html#block>`_ и сохраняется в
неизменяемом хранилище блоков (блокчейн).

Транзакции состоят из команд, выполняющих действие над
`сущностью <../concepts_architecture/er_model.html>`_ в системе.
Сущностью может быть аккаунт, актив и т.д.
