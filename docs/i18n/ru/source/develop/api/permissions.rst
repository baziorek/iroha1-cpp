***********
Разрешения
***********

Hyperledger Iroha использует систему контроля доступа на основе
ролей для ограничения действий своих пользователей.
Эта система очень помогает реализовывать сценарии использования с
группами пользователей, имеющими разные уровни доступа — от
слабых пользователей, которые даже не могут получить перевод
активов, до суперпользователей.
Красота нашей системы разрешений в том, что вам не нужен
суперпользователь в вашей установке Iroha или использование всех
возможных разрешений: вы можете создавать сегрегированные и
лёгкие роли.

Обслуживание системы включает настройку ролей и разрешений,
включённых в роли. Это может быть сделано на начальном этапе
развёртывания системы — в genesis block — или позже, когда сеть
Iroha уже работает, роли могут быть изменены (если есть роль,
которая может это сделать :).

Этот раздел поможет понять разрешения и даст представление о том,
как создавать роли, включающие определённые разрешения.
Каждое разрешение сопровождается примером на Python, который
демонстрирует способ создания транзакции или запроса,
требующего конкретного разрешения. Каждый пример использует
модуль *commons.py*, листинг которого доступен в разделе
`Supplementary Sources`_.
