================
Develop on Iroha
================

Iroha — отличная серверная часть для ваших приложений,
работающих с распределёнными реестрами. В этом разделе мы
рассмотрим инструменты (справочник API и библиотеки) и примеры,
которые можно использовать.

Вы также можете посмотреть `The Borsello App
<https://github.com/claudiocandio/borsello>`_ — это кошелёк для
Android и iOS вместе с веб-приложением, созданный `Claudio
<https://github.com/claudiocandio>`_. Он может помочь понять общую
идею того, как фронтенд может использоваться с HL Iroha. Вы также
можете посмотреть `пример веб-кошелька на JavaScript
<https://github.com/soramitsu/iroha-wallet-js>`_, написанного на
`Vue <https://vuejs.org/>`_.
