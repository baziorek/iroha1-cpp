.. _iroha-cli:

======================
``iroha-cli``
======================

``iroha-cli`` — консольный клиент Iroha: интерактивный инструмент для
отправки транзакций и запросов пиру без написания кода. Поставляется
вместе с ``irohad`` в каждом дистрибутиве — выберите тот, что у вас уже
есть.

Получение ``iroha-cli``
-----------------------

Docker
^^^^^^

Если узел запущен из официального образа, ``iroha-cli`` уже внутри
контейнера:

.. code-block:: shell

  docker exec -it iroha iroha-cli -account_name admin@test

Аргумент ``-account_name`` выбирает, чьей парой ключей подписываются
транзакции — в примере конфигурации это ``admin@test`` (ключ лежит
рядом с остальными файлами в ``example/``).

AppImage
^^^^^^^^

Скачайте ``iroha-cli-x86_64.AppImage`` со страницы
`GitHub Releases <https://github.com/baziorek/iroha1-cpp/releases>`__
вместе с ``irohad``, сделайте исполняемым и запустите:

.. code-block:: shell

  chmod +x iroha-cli-x86_64.AppImage
  ./iroha-cli-x86_64.AppImage -account_name admin@test

.. note:: AppImage ``iroha-cli`` публикуется с релизом ``1.6.1`` —
  см. :ref:`node-appimage`.

Сборка из исходников
^^^^^^^^^^^^^^^^^^^^

При :ref:`сборке Iroha из исходников <node-build>` ``iroha-cli``
появляется рядом с ``irohad``:

.. code-block:: shell

  ./build/bin/iroha-cli -account_name admin@test

Первый запуск
-------------

Независимо от дистрибутива первый запуск спросит адрес и порт пира —
для локального узла это ``localhost`` и ``50051`` (``torii_port`` из
конфигурации узла). Дальше интерактивное меню позволяет составлять
транзакции (``tx``) и запросы (``qry``), отправлять их пиру и проверять
статусы транзакций.

.. note:: ``iroha-cli`` покрывает только самые частые команды — это
  вспомогательный инструмент, а не полный API. Полный разбор отправки
  первой транзакции — в :doc:`cli-guide`; программный доступ описан в
  :doc:`python-guide` и `справочнике API
  <../develop/api/commands.html>`_.
