.. _node-build:

======================================
Узел Iroha, собранный из исходников
======================================

Сборка Iroha из исходников даёт ``irohad`` (узел) и ``iroha-cli``
(консольный клиент) в виде обычных бинарников — так же, как
производятся релизные пакеты, но с полным контролем над флагами
компилятора, патчами и конфигурацией.

Полное платформо-специфичное руководство по сборке — требования,
сборка зависимостей vcpkg, опции CMake и устранение неполадок —
находится в разделе :ref:`build-guide`. Кратко:

#. Установите требования toolchain для вашей платформы
   (Linux/macOS или Windows через WSL).
#. Один раз соберите зависимости через ``./vcpkg/build_iroha_deps.sh``.
#. Настройте и соберите:

   .. code-block:: shell

     cmake -S . -B build \
         -DCMAKE_TOOLCHAIN_FILE=$PWD/vcpkg-build/scripts/buildsystems/vcpkg.cmake \
         -DCMAKE_BUILD_TYPE=Release
     cmake --build build --target irohad iroha-cli -j$(nproc)

Готовые бинарники попадают в ``build/bin/`` (``irohad``,
``iroha-cli``).

Запуск узла
-----------

Самостоятельно собранный ``irohad`` принимает те же флаги командной
строки, что и сборка AppImage — полный пример первого запуска смотрите
в :ref:`node-appimage`. Также понадобятся пример конфигурации из
``example/`` (config, genesis block, ключи).

.. hint:: Если нужен просто работающий узел, варианты
  :ref:`Docker <node-docker>` или :ref:`AppImage <node-appimage>`
  быстрее — сборка из исходников в основном для разработчиков,
  планирующих изменять саму Irohу.
