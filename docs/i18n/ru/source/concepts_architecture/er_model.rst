Модель сущностей и связей
=========================

Каждый пир Hyperledger Iroha имеет состояние, называемое "World
State View", которое представлено набором сущностей и связей
между ними. Чтобы объяснить, какие сущности существуют в системе
и какие между ними связи, этот раздел включает ER-диаграмму и
описание её компонентов.

ER-диаграмма
------------

.. image:: ./../../image_assets/er-model.png

Peer
----

 - address — сетевой адрес и внутренний порт, используется для
   синхронизации, консенсуса и связи со службой ordering
 - public_key — ключ, который будет использоваться для подписи
   блоков в процессе консенсуса

Asset
-----

 - asset_id — идентификатор актива, форматируется как
   asset_name#domain_id
 - domain_id — идентификатор домена, где был создан актив,
   ссылка на существующий домен
 - precision — размер дробной части

Signatory
---------

 - public_key — публичный ключ

Domain
------

 - domain_id — идентификатор домена
 - default_role — роль по умолчанию на пользователя,
   созданного в домене, ссылка на существующую роль

Role
----

 - role_id — идентификатор роли

RoleHasPermissions
^^^^^^^^^^^^^^^^^^

 - role_id — идентификатор роли, ссылка на существующую роль
 - permission_id — идентификатор разрешения

Account
-------

 - account_id — идентификатор аккаунта, форматируется как
   account_name@domain_id
 - domain_id — идентификатор домена, где был создан аккаунт,
   ссылка на существующий домен
 - quorum — количество подписантов, необходимое для создания
   валидной транзакции с этого аккаунта
 - transaction_count – счётчик транзакций, созданных этим
   аккаунтом
 - data — хранилище ключ-значение для любой информации,
   связанной с аккаунтом. Размер ограничен 268435455 байтами
   (0x0FFFFFFF) (поле PostgreSQL JSONB).

AccountHasSignatory
^^^^^^^^^^^^^^^^^^^

 - account_id — идентификатор аккаунта, ссылка на существующий
   аккаунт
 - public_key — публичный ключ (также называемый подписантом),
   ссылка на существующего подписанта

AccountHasAsset
^^^^^^^^^^^^^^^

 - account_id — идентификатор аккаунта, ссылка на существующий
   аккаунт
 - asset_id — идентификатор актива, ссылка на существующий актив
 - amount — количество актива, принадлежащее аккаунту

AccountHasRoles
^^^^^^^^^^^^^^^

 - account_id — идентификатор аккаунта, ссылка на существующий
   аккаунт
 - role_id — идентификатор роли, ссылка на существующую роль

AccountHasGrantablePermissions
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

 - account_id — идентификатор аккаунта, ссылка на существующий
   аккаунт. Этот аккаунт даёт передаваемое разрешение на
   выполнение операции над собой получателю разрешения.
 - permittee_account_id — идентификатор аккаунта, ссылка на
   существующий аккаунт. Этому аккаунту даётся разрешение на
   выполнение операции над account_id.
 - permission_id — идентификатор grantable_permission
