=========================
Понятия и архитектура
=========================

Iroha — это система, оперирующая различными понятиями; для удобства
стоит с ними ознакомиться, чтобы понимать, с чем предстоит работать.
Это можно сделать в разделе «Основные понятия».

Чтобы узнать, из чего состоит Iroha, загляните в раздел «Что внутри
Iroha?»
