Настройка TLS для связи клиент-пир (torii)
==========================================

По умолчанию связь клиент-пир не шифруется.
Чтобы включить её, нужно:

1. `Сгенерировать <#generating-keys>`_ пару ключ/сертификат для
   каждого пира
2. Распространить сертификат всем клиентам
3. `Настроить <#configuring-irohad>`_ irohad для использования
   этих ключей
4. [Пере]запустить irohad


Генерация ключей
~~~~~~~~~~~~~~~~

Ключи должны быть в формате PEM. Для их генерации можно
использовать ``openssl``:

.. code-block:: sh

    $ openssl genpkey -algorithm rsa -out server.key
    $ openssl req -new -key server.key -x509 -out server.crt

Можно использовать любой алгоритм вместо ``rsa``, пока ваш
``openssl`` его поддерживает.
Чтобы узнать, какие поддерживаются, используйте

.. code-block:: sh

    $ openssl list-public-key-algorithms

Если нужно использовать обычные IP-адреса для подключения к
узлу, необходимо указать ``subjectAltName`` в сертификате
сервера — для этого добавьте директиву ``subjectAltName`` в
секцию ``v3_ca`` конфигурации openssl перед генерацией
сертификата.
Например, для установки по умолчанию, ``/etc/ssl/openssl.cnf``:

.. code-block:: text

    [ v3_ca ]
    subjectAltName=IP:12.34.56.78

Поля в сертификате на самом деле не важны, кроме Common Name
(CN) — он проверяется относительно имени хоста клиента, и TLS
handshake завершится неудачей, если они не совпадают (напр. если
вы подключаетесь к example.com:50051, irohad на example.com
должен иметь example.com в common name сертификата).

Настройка irohad
~~~~~~~~~~~~~~~~

Чтобы настроить irohу на использование ваших ключей, нужно
изменить параметр конфигурации ``torii_tls_params``.

Он должен выглядеть как следующий блок:

.. code-block:: javascript

    "torii_tls_params": {
        "port": 55552,
        "key_pair_path": "/path/to/server"
    }

``port`` - установите на любой порт (но обычно нужен 55552)

``key_pair_path`` - установите на полный путь к паре
ключ/сертификат, так что если у вас ключ в
``/path/to/server.key`` и сертификат в ``/path/to/server.crt``,
нужно указать ``torii_tls_keypair=/path/to/server``

.. note:: В `каталоге примеров
  <https://github.com/baziorek/iroha1-cpp/tree/iroha1-main/example/torii_tls>`_
  есть образцы сертификатов, но для включения TLS вам нужен новый
  сертификат для вашего сервера (образец не сработает).
