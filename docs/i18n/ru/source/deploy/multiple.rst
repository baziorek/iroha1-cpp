==========================================
Запуск нескольких экземпляров (сеть пиров)
==========================================

Чтобы настроить сеть пиров, следует следовать процедурам,
описанным в этом разделе. В этой версии мы поддерживаем ручное
развёртывание и автоматизированное через Ansible Playbook.
Выберите вариант, соответствующий вашим критериям безопасности и
другим потребностям.

Вручную
-------

Под ручным развёртыванием мы имеем в виду настройку сети пиров
Iroha без автоматизации. Это похоже на процесс запуска
одиночного локального экземпляра, хотя разница в том, что genesis
block включает более одного пира. Чтобы сформировать блок,
включающий более одного пира, или требующий настройки под ваши
нужды, посмотрите раздел :ref:`deploy_troubles`.

Автоматически
-------------

`iroha-swarm <https://github.com/kuvaldini/iroha-swarm>`_
генерирует конфигурационные файлы для docker-compose для запуска
нескольких узлов Iroha одной командой. Вы можете выбрать тип
базы данных — RocksDB или Postgres — указать ключи пиров или
использовать сгенерированные. Очень удобно для генерации
базового/первого конфигурационного файла и для регулярно
меняющегося окружения (разные наборы узлов).

.. note:: ``iroha-swarm`` — инструмент сообщества, не
  поддерживается с ~2019 — проверьте его внимательно перед
  использованием; он может ссылаться на теги образов, которых
  больше нет (например, ``:latest``).

Также есть `руководство
<https://github.com/hyperledger/iroha-deploy/blob/master/ansible/roles/iroha-docker/README.md>`__
(архивный репозиторий), которое может быть устаревшим, но может
предоставить полезную информацию.
