=========================================
Развёртывание Iroha в кластере Kubernetes
=========================================

.. warning:: **Это руководство носит исторический характер и не может быть выполнено.**

  Оно описывает развёртывание Iroha 1 в Kubernetes с помощью
  Terraform, Ansible и Kubespray, используя каталог ``deploy/``
  апстрим-репозитория. Этот каталог — модули Terraform,
  плейбуки Ansible, субмодуль Kubespray, манифесты k8s —
  **больше не является частью исходников Iroha 1** и не
  поддерживается. Оригинальные материалы сохранены в истории
  апстрим-репозитория; см.
  `hyperledger-iroha/iroha <https://github.com/hyperledger-iroha/iroha>`__
  (ветка ``iroha1-main`` и более ранние теги, например
  ``v1.5.0``).

Что это руководство раньше охватывало
--------------------------------------

- provisionирование кластера Kubernetes на AWS с помощью
  Terraform + Kubespray,
- генерацию конфигураций и ключей пиров Iroha с помощью
  плейбуков Ansible из ``deploy/ansible/``,
- развёртывание мультипировой сети Iroha в кластере.

Если сегодня вам нужен Iroha в Kubernetes, практические
варианты:

- запуск ``irohad`` (или community-образа Docker/Podman) как
  StatefulSet с постоянными томами для block store и WSV за
  собственным ingress с терминацией TLS — см. :ref:`deploy-guide`
  и :doc:`../configure/torii-tls`;
- для одннодового развёртывания проще использовать выпущенные
  пакеты ``.deb``/``.rpm`` или AppImage — см. :ref:`getting-started`.
