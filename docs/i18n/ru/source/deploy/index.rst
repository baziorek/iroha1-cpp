======
Deploy
======

Hyperledger Iroha можно развернуть разными способами в зависимости
от целей и перспективы. Это может быть один узел или несколько
узлов, работающих в нескольких контейнерах на локальной машине
или распределённых по сети — выбирайте вариант, который вам
нужен. Эта страница описывает разные сценарии и служит
инструкцией для пользователей, впервые пробующих Irohу.

.. rubric:: Историческая заметка

Старые релизы Iroha 1 содержали версию gRPC, уязвимую к
`grpc/grpc#20418 <https://github.com/grpc/grpc/issues/20418>`_,
где legacy polling engine ``epollex`` мог исчерпать файловые
дескрипторы и вызвать падение узла на macOS и старых ядрах
Linux. Этот poller был удалён из gRPC в 2022 году, поэтому
текущие сборки (gRPC >= 1.46, event engine) не затронуты —
проблема касается только артефактов, собранных до обновления gRPC.
