Флаги irohad
================

Вы можете запускать ``irohad`` с различными флагами. Некоторые
из основных `уже были упомянуты
<single.html#run-iroha-daemon-irohad>`__, но есть и другие,
которые могут быть полезны в вашей уникальной ситуации. Вот они:

+--------------------------+-----------------------------------------------------------------------+------------+---------------+
| Флаг                     | Описание                                                              | Тип        | По умолчанию  |
+==========================+=======================================================================+============+===============+
| ``-config``              | указывает путь provisioning Iroha                                     | ``string`` | ""            |
| ``-drop_state``          | удаляет существующие данные состояния при запуске                     | ``bool``   | false         |
| ``-genesis_block``       | указывает файл с начальным блоком                                     | ``string`` | ""            |
| ``-keypair_name``        | указывает имя файлов .pub и .priv                                     | ``string`` | ""            |
| ``-metrics_addr``        | адрес прослушивания HTTP-сервера Prometeus                            | ``string`` | "127.0.0.1"   |
| ``-metrics_port``        | порт прослушивания HTTP-сервера Prometeus, по умолчанию выключен      | ``string`` | ""            |
| ``-overwrite_ledger``    | перезаписывает данные ledger, если они существуют                     | ``bool``   | false         |
| ``-reuse_state``         | пытается переиспользовать существующие данные состояния при запуске   | ``bool``   | true          |
|                          | (устарело — запуск по умолчанию переиспользует состояние; используйте |            |               |
|                          | ``drop_state``, чтобы удалить WSV)                                    |            |               |
| ``-verbosity``           | подробность логирования                                               | ``string`` | "config_file" |
| ``-wait_for_new_blocks`` | политика синхронизации при запуске — ждёт новые блоки в blockstore,   | ``bool``   | false         |
|                          | не запускает сеть                                                     |            |               |
| ``-exit_after_init``     | перестраивает WSV из хранилища блоков и завершается; полезно для      | ``bool``   | false         |
|                          | ремонта состояния или переиндексации                                  |            |               |
| ``-syncing_node``        | запускает узел в режиме syncing: следует за цепочкой от пиров без     | ``bool``   | false         |
|                          | участия в консенсусе (см. :ref:`syncing-node`)                        |            |               |
+--------------------------+-----------------------------------------------------------------------+------------+---------------+
