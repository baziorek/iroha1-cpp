======================
PostgreSQL vs. RocksDB
======================

Iroha を使用する際、PostgreSQL（リレーショナルデータベース）ま
たは RocksDB（key-value）のどちらかでビルドして使用するかを
選択できます。

どちらのオプションも信頼でき、本番環境で使用できますが、選択
に役立ついくつかの重要な違いがあります。

PostgreSQL の固有の特徴:
************************

- クラシックなデータベースオプション — つまり、それを扱う多
  くのツールがある
- Iroha が Docker で動作する場合、PostgreSQL は別のコンテナで
  動作する
- データ量が多いと PostgreSQL が遅くなる可能性がある

.. tip:: このデータベースについては、そのドキュメントで詳しく
  学べます: https://www.postgresql.org/docs/

RocksDB の固有の特徴:
**************************

- 高速（`パフォーマンステスト結果
  <https://wiki.hyperledger.org/display/iroha/Release+1.3.0>`__
  を参照）
- RocksDB は組み込み — WSV とブロックストアの両方が同じデー
  タベースにあるため一貫性が高いが、データベースへのアクセ
  スを持つハッシュを手動で追加できる可能性があり、セキュリ
  ティ上の懸念を引き起こす可能性がある
- ディスク上の占有スペースが少なく、大きくなりすぎるという情
  報はない

.. tip:: このデータベースについては、そのドキュメントで詳しく
  学べます: https://rocksdb.org/docs/getting-started.html
