================
Develop on Iroha
================

Iroha は、分散型台帳上で動作するアプリケーションの優れた
バックエンドです。このセクションでは、ツール（API リファレンス
とライブラリ）とそれを使ったユースケースを紹介します。

`The Borsello App
<https://github.com/claudiocandio/borsello>`_ もチェックして
みてください — `Claudio
<https://github.com/claudiocandio>`_ による Android と iOS
向けウォレットで、Web ブラウザアプリケーションも含まれていま
す。フロントエンドが HL Iroha とどう連携できるかの全体像を理解
するのに役立つかもしれません。また、`Vue
<https://vuejs.org/>`_ で開発された `サンプルの Web
JavaScript ウォレット
<https://github.com/soramitsu/iroha-wallet-js>`_ もご覧ください。
