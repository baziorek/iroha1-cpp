iOS Swift ライブラリ（メンテナンスされていません）
--------------------------------------------------

.. note::
   このページはアップストリームの ``iroha-ios`` ライブラリを説明
   しています。これは **2020 年以降メンテナンスされていません**
   （最終リリース v4.0.1）— Iroha 1 ノードでは引き続き動作します
   が、更新はありません。新しいプロジェクトには、このフォークの
   積極的にメンテナンスされている :doc:`cpp` または
   :doc:`python` ライブラリを推奨します。

このライブラリは、トランザクション/クエリの送信、トランザクショ
ンステータスとブロックコミットのストリーミングを含む、Iroha ブロ
ックチェーンと通信するための iOS アプリケーション向けの便利な
インターフェースを提供するために作成されました。

入手先
^^^^^^

Iroha iOS ライブラリは CocoaPods を通じて利用できます。インストー
ルするには、Podfile に次の行を追加するだけです:

.. code-block:: swift

    pod 'IrohaCommunication'

ライブラリのソースコードは `そのリポジトリ
<https://github.com/hyperledger/iroha-ios>`__ からダウンロードする
こともできます


使用方法
^^^^^^^^

新しい Iroha ユーザーには `iOS サンプルプロジェクト
<https://github.com/hyperledger/iroha-ios/tree/master/Example>`__
を確認することをお勧めします。コンピュータ上でローカルに実行され
ている Iroha ピアに接続を確立し、新しいアカウントを作成してアセッ
ト数量を送信しようとします。
プロジェクトを実行するには、以下の手順に従ってください:

- Iroha ドキュメントの手順に従って、Docker コンテナで Iroha ピア
  をセットアップして実行します。

- `iroha-ios リポジトリ
  <https://github.com/hyperledger/iroha-ios>`__ をクローンします。

- Example ディレクトリに移動し、pod install を実行します。

- XCode で IrohaCommunication.xcworkspace を開きます。

- IrohaExample ターゲットをビルドして実行します。

- シナリオが正常に完了したかどうかを確認するためにログを確認しま
  す。

サンプルプロジェクトを自由に実験し、`Discord
<https://discord.com/channels/905194001349627914/905205848547155968>`__
で質問があればお気軽にどうぞ。
