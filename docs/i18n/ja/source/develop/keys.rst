====================
鍵ペアのフォーマット
====================

Iroha はトランザクションに署名するために鍵ペア（.pub と .priv
鍵）を使用します — すべての `アカウント
<../concepts_architecture/glossary.html#account>`__ は少なくとも
1 つのペアを持っています。一部のアカウント（`quorum
<../concepts_architecture/glossary.html#quorum>`__ が 1 より大きい
場合）は、トランザクションに署名する `署名者
<../concepts_architecture/glossary.html#signatory>`__ をより多く
持つことがあり — 各署名者は鍵ペアを持っています。暗号アルゴリズム
はこれらの鍵を使用します — Iroha では使用するアルゴリズムを選択で
きます。

.. note:: Python ライブラリを使用した鍵ペアの作成方法は `こちら
   <../getting_started/python-guide.html#creating-your-own-key-pairs-with-python-library>`__
   を参照してください。

サポートされる暗号アルゴリズム
===============================

ネイティブに、HL Iroha はカスタムアルゴリズム — SHA-3 を使用する
Ed25519 — を使用します。これらの鍵は古いバージョンを含むすべての
Iroha バージョンでサポートされています。しかし皆さんご存知のとおり
、より汎用的なオプションも必要です — それが Iroha に `HL Ursa
統合 <../integrations/index.html#hyperledger-ursa>`__ がある理由
です — これはさまざまな暗号アルゴリズムを持つライブラリで、より
主流の鍵を使用して Iroha と連携できます。Ursa は Iroha に SHA-2
アルゴリズムを使用する標準 Ed25519 のサポートを提供します。

公開鍵
------

後方互換性を「壊さず」に異なるアルゴリズムを使用できる簡単なソ
リューションを提供するため、Iroha の公開鍵に **multihash**
フォーマットを導入しました。multihash については `こちら
<https://github.com/multiformats/multihash>`__ で詳しく学べます。

一般に、ネイティブの SHA-3 ed25519 鍵とは異なる鍵を使用するには、
それらをこのフォーマットに変換する必要があります:

.. code-block:: shell

	<varint key type code><varint key size in bytes><actual key bytes>


.. note:: multihash では、varint は最上位ビットの符号なし
   varint（base-128 varint とも呼ばれる）です。


Iroha が 32 バイトの標準公開鍵を受け取ると、それをネイティブの
Iroha 鍵として扱います。multihash 公開鍵を受け取ると、以下の表に
基づいて扱います。


現在、Iroha が「理解」する multihash 鍵フォーマットは 1 つだけで
す:

+------------+-----------+----------+------------------+
|名前        |タグ       |コード    |説明              |
+============+===========+==========+==================+
|ed25519-pub |key        |0xed	    |Ed25519 公開鍵    |
+------------+-----------+----------+------------------+

Iroha の公開鍵の例:

+----------------+--------+----------+-------------------------+----------------------+
| タイプ         | コード | 長さ     | データ                  | Iroha が認識するもの |
+================+========+==========+=========================+======================+
| multihash 鍵   | ED01   | 20       | 62646464c35383430b...   | ed25519/sha2         |
+----------------+--------+----------+-------------------------+----------------------+
| 生の 32 バイト | --     | --       | 716fe505f69f18511a...   | ed25519/sha3         |
| 鍵             |        |          |                         |                      |
+----------------+--------+----------+-------------------------+----------------------+

コード `0xED` は multihash フォーマットの規則により `ED01` として
エンコードされることに注意してください。

秘密鍵
------

Ursa の **秘密鍵** は、秘密鍵と公開鍵の連結で表現されます —
multihash プレフィックスなしで。
