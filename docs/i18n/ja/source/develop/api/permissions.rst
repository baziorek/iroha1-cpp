**************
パーミッション
**************

Hyperledger Iroha はロールベースのアクセス制御システムを使用して
ユーザーのアクションを制限します。このシステムは、異なるアクセ
スレベルを持つユーザーグループを含むユースケースの実装に大いに
役立ちます — アセット転送を受け取ることさえできない弱いユーザー
からスーパーユーザーまで。私たちのパーミッションシステムの美し
さは、Iroha セットアップにスーパーユーザーを持つ必要も、すべての
可能なパーミッションを使用する必要もないことです。分離された軽
量なロールを作成できます。

システムの維持には、ロールに含まれるロールとパーミッションの設定
が含まれます。これはシステムデプロイの初期段階 — genesis
block — で行うことも、Iroha ネットワークが稼働した後で行うことも
できます（それができるロールがある場合 :）。

このセクションでは、パーミッションを理解し、特定のパーミッション
を含むロールの作成方法のアイデアを提供します。
各パーミッションには、特定のパーミッションを必要とするトランザ
クションまたはクエリの作成方法を示す Python で書かれた例が付い
ています。すべての例は *commons.py* モジュールを使用しており、
そのリストは `Supplementary Sources`_ セクションで確認できます。
