====================
RocksDB
====================

IrohaはPostgresまたはRocks Databaseを使用できます。
お好みの方を選んで構いませんし、切り替えたい場合の方法も
あります。**データベースを移行するだけです！**
その方法は次の通りです。

.. hint:: 移行ツールとWSVチェッカーの両方に ``-help`` が
   あり、いつでも利用可能なフラグを確認できます。

移行方法
========

Irohaをビルドした後（または単に
`Dockerイメージ <https://hub.docker.com/r/hyperledger/iroha>`_
をpullした後）、バージョン1.3（またはそれ以降）では
移行ツールがすでに独立した実行ファイルとして用意されて
います！デフォルトでは、ビルド後にIrohaはバイナリを
``BUILD_DIR/bin/`` に格納します。

次のフラグを付けて ``iroha_migrate`` を実行するだけです:

- ``-help`` - ヘルプ
- ``-block_store_path`` - block storeのパスを指定します。
  デフォルト: "/tmp/block_store"
- ``-export`` - block storeを指定したディレクトリにエクス
  ポートします。デフォルトはカレントワーキングディレクトリ
  (CWD) です。RocksDBへの *逆方向* の移行（そこからファイルを
  エクスポートする）に使用します。
- ``-drop_state`` - RocksDBのblockstoreにすでにブロックが
  ある場合に上書きするために使用します。移行したデータベース
  の整合性を確認する次のステップがエラーで失敗し、移行
  プロセスを繰り返す必要がある場合に非常に役立ちます。
  デフォルト: false
- ``-rocksdb_path`` - RocksDBのパスを指定します。
  デフォルト: "rocks.db"

移行が失敗した場合、ゼロ以外のコードで終了します。その場合は
すべてのフラグを確認して再試行してください。


そして…データベースの移行が完了しました！でもまだ終わり
ではありません。

移行プロセスが成功したことを確認するため、続いてWSV
チェックを使用します。

移行後のWSVの確認方法
======================

``iroha_wsv_diff`` を次のフラグで実行します:

- ``-help`` - ヘルプ
- ``-pg_opt`` - Postgresオプション文字列を指定します。設定と
  同じものである必要があります。デフォルト:
  "dbname=iroha_default host=localhost port=5432 user=postgres
  password=postgres"
- ``-rocksdb_path`` - RocksDBのパスを指定します。
  デフォルト: "rocks.db"

データベースが同一であれば、Mr. Spockが表示されます。
（SFの大ファンでなければ）終了コードもゼロになります。

差異がある場合は、``-drop_state`` フラグを付けて移行ツールを
再度使用することをお勧めします。

不一致の場合、コマンドはゼロ以外のコードで終了します。差異は
コンソールに報告され、両方のデータベースの完全なWSVが対応する
ファイルに保存されます（``postgres.wsv`` と ``rocksdb.wsv``
の結果はカレントワーキングディレクトリ (CWD) に出力されます）。
今後の調査のために、WSV間の正確な差異を確認するには任意の
diffツールを使用できます。
