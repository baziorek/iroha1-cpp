========================
移行のベストプラクティス
========================

Iroha のメンテナーは、プロジェクトを Iroha の新しいバージョンに
移行する最良の方法についてよく質問を受けます。そこで、私たちと
私たちのプロジェクトで最もうまくいったプラクティスを共有する
ことにしました。

**4 ピアのネットワークの例で、移行手順（PostgreSQL データベース
から RocksDB への移行も兼ねる）を見ていきます。これは私たちの
プロジェクトで最も安定し信頼できるものでした。**

手順は次のとおりです:
*********************

1. 4 つのノードが古いバージョンの Iroha を Postgres で実行して
   いる状態から始めます
2. `Iroha データベース移行 <migration-rocksdb.html>`_ の手順に
   従います。RocksDB フォルダーをコピーします。*Postgres と
   RocksDB の切り替えが不要な場合はこのステップをスキップ*
3. `Add Peer コマンド <add_peer.html>`_ を使って、RocksDB
   フォルダーを持つ新しいバージョンの Iroha を実行する新しい
   ピアを追加します
4. 同様のノードをさらに 2 回追加します
5. これで 7 つのノードができます — 古いバージョンの 4 つと
   新しいバージョンの 3 つ
6. 古いバージョンの最初のノードをシャットダウンし、同じ鍵ペア
   で新しいバージョン（目標が RocksDB ならそれも）に更新します
7. 古いバージョンの Iroha を持つすべてのノードでこれを繰り返し
   ます
8. これで「新しい」ノードを削除し、プロジェクトの作業を続ける
   ことができます!
