はじめまして。どこから始めればいいですか?
------------------------------------------

こんにちは、新参者の方! ようこそ :)
Iroha を始める方法は 2 つあります:

 1. `クイックスタートガイド
    <../getting_started/index.html>`_ に従ってシンプルな
    例のネットワークを構築し、Iroha が何でどう動くかを見ることが
    できます
 2. `Iroha のコアコンセプト
    <../concepts_architecture/index.html>`_ に慣れ親しみ、
    自分の `Iroha ネットワーク
    <../deploy/index.html>`_ を構築し始めることができます

これであなたの Iroha ブロックチェーンができました! おめでとう
ございます! 質問があれば、ぜひコミュニティにご連絡ください:
https://chat.hyperledger.org/channel/iroha

どんな種類のデータを転送できますか?
------------------------------------

Hyperledger Iroha では、アセット（そのようなアセットを扱う
コマンドとクエリの充実したセットのため、そう思われるかもしれ
ません）だけでなく、チェーンに保存されるあらゆるデータを送信
できます。

現在の実装では、少なくとも `SetAccountDetail
<../develop/api/commands.html#set-account-detail>`_ コマンドと
`GetAccountDetail
<../develop/api/queries.html#get-account-detail>`_ クエリを
通じてその機能を提供しています。

モバイルデバイスをノードにできますか?
--------------------------------------

「モバイルデバイス」が何を指すかによって 2 つの選択肢がありま
す。

ARM ベースのハードウェアに Linux が搭載されている場合
（Raspberry PI など）や、root 化された Android デバイスの場合
は、そのデバイス上で Iroha をノード（ネットワーク内のピア）
として起動できます。その場合、Iroha はプラットフォームネイ
ティブのバイナリとして動作します。

標準的な iOS または Android デバイスで、工場出荷時のシェル
（GUI）がそのままの場合は、一般的に不可能であり、この点に関する
手順は提供していません。ただし、Iroha を使用するモバイル
アプリケーションを作成することはできます。それらは Iroha の
クライアントであり、ピアとして機能することはありません。

ARM デバイスで Iroha を実行するには、ターゲットプラットフォーム
でビルドする必要があります。Iroha のビルドにはかなりの量の
RAM が必要です — 32 ビット ARM ホストでは 8 GB の RAM が必要
です。ビルドは Docker コンテナ内で実行できます。コンテナを
準備するには:

1. Iroha の git リポジトリをクローン:
   https://github.com/baziorek/iroha1-cpp
2. `iroha1-cpp/docker/develop` で `docker build -t iroha-build-env .`
   を実行
3. 新しくビルドしたコンテナを起動し、その中で Iroha 自体を
   ビルド

Iroha の git リポジトリフォルダをコンテナにマウントするのを
忘れないでください。

スループット（TPS）はどのくらいですか? パフォーマンステスト
の結果はありますか?
------------------------------------------

Iroha ネットワークの効率は、構成、ハードウェア、ノード数に
依存します。`test/load` ディレクトリにある負荷テストを試して
結果を報告していただけると幸いです。

Iroha と Iroha 2 の違いは何ですか?
----------------------------------

Iroha 2 は Rust で書き直された Iroha で、コンセンサスメカニズム
にいくつかの大きな変更があります。`Iroha 2 ドキュメント
<https://hyperledger.github.io/iroha-2-docs/guide/iroha-2.html>`_
には、2 つのプロジェクト間の違いの概要が記載されています。
