==========================================
複数インスタンスの実行（ピアネットワーク）
==========================================

ピアネットワークをセットアップするには、このセクションで説明
されている手順に従う必要があります。このバージョンでは、手動
デプロイと Ansible Playbook による自動化をサポートしています。
セキュリティ基準やその他のニーズに合うオプションを選んでくだ
さい。

手動
----

手動デプロイとは、Iroha ピアネットワークを自動化なしで
セットアップすることを意味します。単一のローカルインスタンス
の実行プロセスに似ていますが、違いは genesis block に単一の
ピア以上が含まれることです。複数のピアを含むブロックを形成
するか、ニーズに合わせたカスタマイズが必要な場合は、
:ref:`deploy_troubles` セクションを参照してください。

自動
----

`iroha-swarm <https://github.com/kuvaldini/iroha-swarm>`_ は、
1 つのコマンドラインで多数の Iroha ノードを起動するための
docker-compose 設定ファイルを生成します。データベースの種類
— RocksDB または Postgres — を選択し、ピアの鍵を提供するか
事前生成されたものを使用できます。基本的な/最初の設定ファイ
ル生成や、頻繁に変わる環境（異なるノードセット）に非常に便利
です。

.. note:: ``iroha-swarm`` はコミュニティツールで、~2019 年
  以降メンテナンスされていません — 使用前に注意深く確認して
  ください。存在しなくなったイメージタグ（例: ``:latest``）を
  参照している可能性があります。

また、`ガイド
<https://github.com/hyperledger/iroha-deploy/blob/master/ansible/roles/iroha-docker/README.md>`__
（アーカイブ済みリポジトリ）もあり、古い可能性がありますが
役立つ情報を提供するかもしれません。
