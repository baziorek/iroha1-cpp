irohad フラグ
================

``irohad`` をさまざまなフラグで起動できます。主なものの一部は
`すでに説明しました
<single.html#run-iroha-daemon-irohad>`__ が、独自の状況で役立
つ他のものもあります。以下に示します:

+--------------------------+-------------------------------------------------------------------+------------+---------------+
| フラグ                   | 説明                                                              | 型         | デフォルト    |
+==========================+===================================================================+============+===============+
| ``-config``              | Iroha プロビジョニングパスを指定                                  | ``string`` | ""            |
| ``-drop_state``          | 起動時に既存の状態データを削除                                    | ``bool``   | false         |
| ``-genesis_block``       | 初期ブロックを含むファイルを指定                                  | ``string`` | ""            |
| ``-keypair_name``        | .pub および .priv ファイルの名前を指定                            | ``string`` | ""            |
| ``-metrics_addr``        | Prometeus HTTP サーバーのリッスンアドレス                         | ``string`` | "127.0.0.1"   |
| ``-metrics_port``        | Prometeus HTTP サーバーのリッスンポート、デフォルトは無効         | ``string`` | ""            |
| ``-overwrite_ledger``    | 既存の場合、ledger データを上書き                                 | ``bool``   | false         |
| ``-reuse_state``         | 起動時に既存の状態データを再利用しようとする（非推奨 — 起動時に   | ``bool``   | true          |
|                          | デフォルトで状態を再利用します。WSV を削除するには ``drop_state`` |            |               |
|                          | を使用）                                                          |            |               |
| ``-verbosity``           | ログの詳細度                                                      | ``string`` | "config_file" |
| ``-wait_for_new_blocks`` | 起動同期ポリシー — ブロックストアの新しいブロックを待ち、         | ``bool``   | false         |
|                          | ネットワークを実行しない                                          |            |               |
| ``-exit_after_init``     | ブロックストアから WSV を再構築して終了; 状態の修復や             | ``bool``   | false         |
|                          | 再インデックスに便利                                              |            |               |
| ``-syncing_node``        | ノードを syncing モードで実行: コンセンサスに参加せずピアから     | ``bool``   | false         |
|                          | チェーンに追従（:ref:`syncing-node` を参照）                      |            |               |
+--------------------------+-------------------------------------------------------------------+------------+---------------+
