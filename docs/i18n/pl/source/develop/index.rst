================
Develop on Iroha
================

Iroha jest świetnym backendem dla Twoich aplikacji działających na
rozproszonych ledgerach. W tej sekcji omówimy narzędzia (dokumentacja
API i biblioteki) oraz przypadki użycia.

Możesz też sprawdzić `The Borsello App
<https://github.com/claudiocandio/borsello>`_ — to portfel na
Androida i iOS-a wraz z aplikacją webową, autorstwa `Claudio
<https://github.com/claudiocandio>`_. Może pomóc zrozumieć ogólną
ideę, jak frontend może współpracować z HL Iroha. Możesz też
zobaczyć `przykładowy webowy portfel w JavaScript
<https://github.com/soramitsu/iroha-wallet-js>`_ napisany w
`Vue <https://vuejs.org/>`_.
